# 计算机就业与申博导航

将原有的交互式资源导航整理成一个可部署到 GitHub Pages 的静态网页应用。

## 功能

- 搜索资源、路线任务、申请记录、计划、目标、材料和模板。
- 按方向筛选并收藏资源；可以添加个人资源。
- 勾选就业与申博行动路线，展开 36 项任务的步骤、完成标准、常见误区与相关资源。
- 各栏目提供使用指引，资源卡片说明建议产出；路线内补充就业与科研方向的准备切入点。
- 管理申请状态、下一步动作和截止日期。
- 在月历中查看申请截止事项。
- 创建、编辑和完成自己的计划任务。
- 并排比较最多四个岗位或博士项目。
- 按共同基础、就业按需、申博按需选用 9 项材料预设，附检查提示；记录状态、版本和对应目标。
- 使用 11 份模板，覆盖项目描述、导师联系、SOP、目标比较、JD 对照、论文阅读、面试、每周复盘，以及大陆、香港、澳门博士申请核对表。
- 导入或导出个人数据。

## 分栏操作

- 总览显示当前方向未来 7 天截止、日期已过需复核、未完成计划及全部目标的待备材料；点击数字可查看对应记录。
- 资源库支持排序，每页最多 24 项；搜索与筛选会返回第一页，286 个入口共 12 页。
- 行动路线支持全部、未完成、已完成筛选，显示阶段进度，并可统一展开或收起任务详情。
- 申请看板显示六种状态的数量，可按关键词、状态或截止时间筛选；录取和已结束项不计入进行中提醒。
- 日历补充本月事项列表与就业、申博颜色说明，可只看进行中申请；仅显示申请看板日期。
- 计划与材料提供完成进度、关键词和状态筛选；日期已过表示个人安排需复核，不代表官方申请失效。
- 目标对比提示未填写条件，最多四个目标，达到上限仍可编辑。填写数量不评价目标质量。
- 模板按就业、申博和通用分组；备份区显示将导出的记录数量，清空操作折叠展示。
- 录入表单可展开或收起；编辑自动展开，搜索跳转清除会遮挡结果的筛选。筛选和分页不写入个人备份。

## 资源覆盖

内置 286 个资源。基础扩充新增 85 个入口：24 个招聘及远程机会入口、20 个学习入口、4 个开源入口、10 个论文与数据入口、7 个资助入口和 20 个院校招生入口。部分资源适用于双轨，不应将方向筛选结果相加计数。地区筛选来自实际数据，含中国大陆、中国香港、中国澳门、北美、加拿大、欧洲、日本、新加坡及全球。

新增入口于 2026-10-21 核对官网页面或官方检索资料。遇到网站登录、动态渲染、访问保护或超时的情况已写入对应提示；核对日期不表示实时可访问或仍开放申请。原有 45 个入口保留，本轮未对其作完整重新审查。院校列表用于发现官方入口，不是排名或推荐申请名单。

## 中国大陆与港澳博士申请

- 三地指引增补时新增 30 个官方入口：大陆 18 个、香港 6 个、澳门 6 个。连同原有入口，当前三地申博可用资源分别为 152、10、6 项；计数包含通用招生与资助入口，不等于院校数量。
- 资源库增加三地博士资源快捷筛选；切换时显示申博与通用资源，清除旧搜索、类别及收藏限制，并返回第一页。
- 总览可进入“大陆与港澳申博”；行动路线在双轨或申博范围显示三地指引，覆盖通道、六步准备顺序、材料、资助、误区及官方依据。
- 大陆按报考身份、直博、硕博连读及普通招考核对；香港分开记录研究型录取、校内 Studentship 和 HKPFS；澳门逐校核对博士课程及奖助方案。
- 香港入口覆盖 HKPFS 八所参与大学。教育科技、数据科学等交叉领域需确认正式学位与导师，不表示八校均开设独立计算机 PhD。
- 澳门入口覆盖澳门大学、澳门科技大学、澳门理工大学及澳门城市大学；澳门大学奖助需区分适用入学学年的新旧方案。
- 三份地区核对表可在指引中打开，也可在“模板与备份 → 申博”复制或下载；全局搜索可查地区指引。
- 指引按申请事项推进，不预设统一语言门槛、金额或截止月份。具体资格与期限必须按目标当届官方通知核对；冲突的资格表述须向招生部门确认。
- 内容与入口更新时，地区选择不写入备份，不自动新增申请、计划或材料，原有任务和个人记录格式兼容。

## 中国大陆院校名单

- 按教育部第二轮（2022）双一流名单录入 147 所，包含全部 39 所原 985 对应高校及原 211 对应院校；与已收录的 21 条院校资源合并，新增 126 个入口，总资源数为 286。
- 原 211 使用教育部历史名单的 112 个名称；地矿油各映射为两地办学实体，按本目录口径为 115 条，华北电力北京、保定校区不拆分。147 校并集无额外差集，标签数量不能相加。
- 保留原招生资源 ID 和收藏，支持院校名单与主校所在地组合筛选、全局搜索旧名；医学、艺术等特色院校也完整收录。
- 所在地按主校区：河北工业大学归天津，华北电力归北京。其他校区不单独新增为学校条目。上海体育大学保留第二轮名单中的旧名“上海体育学院”。
- 新增的 126 个入口中，91 个读取了官方研究生页面，30 个依官方检索资料核对，5 个提供学校官网导航；卡片标明核对方式。既有 21 个入口保留此前的核对提示。
- 名单身份不是排名或计算机博士招生资格判断。未逐校确认计算机相关博士点、当前名额或当年开放状态；应从目标当届目录、学院细则及导师信息核实。
- 资源库“大陆院校名单”提供双一流、原 985、原 211 快捷入口；切换会清除旧搜索与其他限制，并返回第一页。名单及所在地筛选不写入个人备份。
- 院校目录新增第四轮（2017）学科评估 0812 计算机科学与技术分档：公开表 168 条，与 147 校目录按办学实体及学校代码匹配 91 所。资源库提供 A 类 / B 类 / C 类快捷筛选与 A+ 至 C− 九档精确筛选，并可与院校名单、所在地、地区、收藏等条件组合。
- 每所院校卡片显示“第四轮 0812 · 等级”徽标；未匹配到的院校标注“未收录”，并说明这不等于未参评或学科弱。
- 第四轮评估是 2017 年的历史参考，不等于当前博士点、招生名额、导师情况或录取难度。申请前仍须查目标当届专业目录与院系细则。

## 数据与隐私

应用没有服务器端，也不要求登录。个人数据保存在当前浏览器的 `localStorage` 中，不会随 GitHub Pages 发布或自动上传。不同设备和浏览器之间不会自动同步；更换设备前请导出 JSON 备份。

应用保留原页面的数据键 `cs-navigator-2026-v1`，并支持导入原页面导出的 v1 备份。新版备份使用 v2 格式。

内容步骤、任务数量和方向提示是规划建议，不代表雇主或院系的统一要求。具体资格、材料和截止时间应到目标官方页面核实。页面不会自动核查资源是否开放，不会换算截止时区或发送系统提醒。日历仅显示申请看板的截止日期；计划和材料日期不会自动同步到日历。内容参考链接位于“模板与备份”。

本地 HTML 和 GitHub Pages 属于不同的网站来源，浏览器不会自动迁移它们的数据。如原页面已有个人进度，请先从原页面导出备份，再在新版网页导入。

## 本地预览

直接用浏览器打开 `index.html`，或在项目目录运行任意静态文件服务器。项目不需要构建步骤，也没有运行时依赖。

## 发布到 GitHub Pages

仓库包含 `.github/workflows/pages.yml`。将项目推送到 `main` 分支后，GitHub Actions 会发布静态文件。

首次发布时，在 GitHub 仓库的 **Settings → Pages → Build and deployment → Source** 中选择 **GitHub Actions**。工作流成功后，GitHub Actions 的部署记录会显示网站地址。
